## Summary

- **A `ralph` bug: `watch_checks` queued every PR before it read CI.** Task 07's R10
  replacement dropped the `if` around both deadline stops, so all 3 runs that passed
  `merge_gate` went to `report_queued` in the same second. No `ralph` run has watched CI, merged
  its own PR, or reached `ci_task`. The 2 `ralph` merges are merge-queue merges. Fixed in
  8e524e9 (*Bugs and fixes*).
- **The Refuter loop works as designed so far.** Both `ralph` runs whose Refuter found a gap it
  could prove turned the findings into Tasks and passed on the next round (writers-app#1168,
  womens-fantasy-sports#2204). The Refuter is `backlog`'s largest held reason: 9 of its 23 PRs.
- **The Iteration loop has not been stressed.** 19 Iterations for 19 Tasks, every one green on
  rung 1. Misses, `## Last attempt` and the ladder are still unexercised.
- **Kimi's quota was out for the whole window.** Every frontier stage failed over: `ralph`'s to
  `glm-5.3` and `backlog`'s to `qwen3.8-27b`. The arms' reviewers and planners ran on different
  models, and `backlog`'s fallback is the only real spend in the window.
- **Diff hygiene's skip counter** held 2 of the 5 `ralph` PRs and 4 of the 23 `backlog` PRs. It is
  a shared gate, not a `ralph` problem. In both repositories the skips are conditional skips.

## Bugs and fixes

**`watch_checks` queued before CI (8e524e9).** `ops/check-graph-invariants.py`'s R10 row for
`watch_checks` replaced each line `if [ … ]; then blocked '…'; fi` with a bare `printf …;
echo …; exit 0`. That dropped the condition. R10 compares the copy with the replacements
applied, so it passed, and no gate test ran `ralph`'s `watch_checks`. The fix restores both
`if`s in the copy and in the R10 row. `test_ralph_watch_checks` now covers green checks inside
the deadline, a spent deadline, and the 47-minute stop. A scan of the other 23 R10 replacements
found no other dropped shell control flow (`mark_stuck`'s dropped `elif` is the draft path that
`ralph` has no use for).

Affected: MHXP6P12, 16TNZAHY, CSV7FHZ8. O3 is shown above with and without them. Every `ralph`
run that starts after the push runs the fixed `watch_checks`.

The tool's *Flags* section now marks a run queued with `watch_checks` under a minute.
