`adr/` holds the decisions. Every other folder is a task series or a set of design records; start each one at its `00-*.md`. `agents/` is reference for agents working in this repo, pointed to from `AGENTS.md`.

Statuses below were moved verbatim from `AGENTS.md` on 2026-10-09; update a row when its series changes state.
